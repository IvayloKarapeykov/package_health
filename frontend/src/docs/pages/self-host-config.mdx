The backend reads its settings from environment variables, or from `backend/.env`. Every one is
optional.

## Keys

| Variable | Default | Description |
| --- | --- | --- |
| `GITHUB_TOKEN` | | Used when a request sends no `X-GitHub-Token` |
| `OPENROUTER_API_KEY` | | Used when a request sends no `X-OpenRouter-Key` |

<Warning>
  On a public server, leave both empty. Otherwise everyone's requests run on your keys and your
  credits.
</Warning>

## Models

| Variable | Default | Description |
| --- | --- | --- |
| `LLM_MODEL` | `z-ai/glm-5.3-flash` | Any OpenRouter model, for summaries, reasons and alternatives |
| `LLM_TEMPERATURE` | `0.2` | |
| `LLM_TIMEOUT_SECONDS` | `60` | |
| `LLM_STRUCTURED_OUTPUT_METHOD` | `function_calling` | `json_schema` or `json_mode` for models without tool calling |
| `USE_JEV_VERDICTS` | `true` | `false` lets the rules decide even with a key |
| `JEV_MODEL` | `typesafe/jev-1.13` | Or `~typesafe/jev-latest` to follow the newest version |

## Limits

| Variable | Default | Description |
| --- | --- | --- |
| `MAX_PACKAGES` | `40` | Most dependencies checked per file |
| `MAX_CONCURRENCY` | `8` | Packages checked at the same time |
| `HTTP_TIMEOUT_SECONDS` | `20` | Timeout for each call to a registry, GitHub or OSV.dev |
| `CACHE_TTL_SECONDS` | `900` | How long registry and GitHub answers are reused |

## Server

| Variable | Default | Description |
| --- | --- | --- |
| `CORS_ORIGINS` | `["http://localhost:5173", "http://127.0.0.1:5173"]` | Sites allowed to call the API from a browser |
| `MCP_ALLOWED_HOSTS` | `["localhost:*", "127.0.0.1:*", "[::1]:*"]` | Host names the `/mcp` endpoint answers to |
| `LOG_LEVEL` | `INFO` | |
| `LOG_FORMAT` | `text` | `json` for one JSON object per line |

Lists are written as JSON, for example `CORS_ORIGINS=["https://example.com"]`.

## Tracing

| Variable | Default | Description |
| --- | --- | --- |
| `LANGSMITH_TRACING` | `false` | Trace every run in [LangSmith](https://smith.langchain.com) |
| `LANGSMITH_API_KEY` | | Required for tracing |
| `LANGSMITH_PROJECT` | `package-health-advisor` | |
| `LANGSMITH_ENDPOINT` | | For the EU region or a self-hosted LangSmith |
| `LANGSMITH_HIDE_INPUTS` | `false` | Keep pasted files out of the traces |

## Frontend

| Variable | Description |
| --- | --- |
| `VITE_API_BASE_URL` | The backend's address, when it's on another domain, e.g. `https://api.example.com` |
